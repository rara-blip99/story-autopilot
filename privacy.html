Privacy Policy

Last updated: 31 October 2026

What this app is

Story Autopilot is a private desktop application that runs only on its owner's computer. It is used exclusively by the owner of the YouTube channel @Draevique to manage that channel.

Data accessed through Google APIs

  • YouTube Data API (youtube.upload, youtube.readonly): to upload the owner's own videos and read basic information about the owner's channel and videos.
  • YouTube Analytics API (yt-analytics.readonly): to read view and engagement statistics of the owner's own channel.

How data is stored

OAuth tokens and statistics are stored only on the owner's computer. Tokens are encrypted with the operating system's user account. No data is sent to any server operated by this app, and no data is sold or shared with third parties.

Use of Google user data

Story Autopilot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's data folder removes all locally stored data.

Contact

Questions: contact the channel owner via youtube.com/@Draevique.
